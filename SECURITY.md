# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/visvaya/wc-2026-bet/security/advisories/new)). Never report a vulnerability in a public issue, pull request or discussion.

Please include:

- the affected file, command or workflow and the commit you tested;
- steps or input that reproduce the problem;
- the impact you expect (for example code execution through a crafted input file, or a leaked CI credential);
- a suggested fix, if you have one.

## Supported versions

Only the latest commit on `main` is supported. There are no releases and no backported fixes.

## Response

The project has a single maintainer, so reports are handled on a best-effort basis without a guaranteed response time. Fixes are published once they are ready, and the report is credited unless you ask otherwise.
